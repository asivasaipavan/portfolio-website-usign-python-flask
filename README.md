# Personal Portfolio — AMBERKAR SIVA SAI PAVAN

Responsive personal portfolio built with Flask, HTML, and CSS.
Shows education, skills, projects, internship experience, certifications, and contact form.

## Features
- Home / About with bio and contact details
- Projects listing
- Contact form that saves messages to `messages.txt`
- Responsive design, ready for local hosting or deployment

## Run Locally
1. Install dependencies:
   pip install -r requirements.txt
2. Run:
   python app.py
3. Visit:
   http://127.0.0.1:5000
